# Проверка версии 2.0 — 4 октября 2026

Движок и шаблоны экспорта: официальный Godot **4.7.2**, контрольные суммы проверены. Облачная среда: Linux, X11/Xvfb, OpenGL Compatibility, Mesa llvmpipe.

- `tests/checks.gd`: **40 проверок, 0 ошибок** — экономика, покупка/разбор, все классы, столкновения, способности, пауза, барьеры, награды, резервные сохранения.
- `tests/story_settings.gd`: **28 проверок, 0 ошибок** — пролог с обязательным поражением, отсутствие наград за него, кража ядра, погоня, перелёт после победы, финал, перенос сохранения 1.0, отдельные громкости, язык, особенности планет.
- `tests/campaign.gd`: **50 из 50 миссий пройдено, 0 ошибок**. Проверочный игрок собирает обычную энергию, покупает доступных роботов и получает награды по порядку. Без бесплатной энергии, мгновенного уничтожения врагов и обхода условий победы.
- `tests/ui_capture.gd`: реальный ввод в исходном проекте — диалоги, выбор семени клавишей, высадка мышью, пауза/продолжение, перетаскивание и сохранение громкости, полноэкранный режим. **12 экранов на трёх языках** отрисованы без отсутствующих переводов; сделаны снимки пяти планет.
- Экспортированная **Linux release** запущена отдельно с новым профилем. Нативными событиями X11/XTest проверены сюжет, управляемый пролог, высадка реактора, пауза, настройки, немецкий язык, ползунок музыки и запись настроек на диск. Использован именно экспортированный исполняемый файл.
- Выход через меню и закрытие окна освобождают музыкальный поток перед завершением процесса; проверено отсутствие ошибок утечки ресурсов.
- Windows x86_64 release экспортирован официальным шаблоном со встроенными ресурсами. Готовый EXE в Windows здесь не запускался. Аудиопроверки проверяют настройки каналов; графические проверки используют Dummy audio driver.

ZIP проекта проверяется после распаковки и импорта в чистую папку; ZIP Windows проверяется на целостность и наличие EXE. Хеши архивов публикуются в `OrbitGuardians-SHA256SUMS.txt` в корне репозитория. Сохранения тестов, кэш Godot и облачные инструменты в архивы не входят.

Новая версия сохраняет прежнее имя папки данных приложения, поэтому смена языка не создаёт отдельный профиль. Исходный README и README готовой сборки описывают запуск и сюжетное поражение, чтобы оно не выглядело ошибкой игры.
