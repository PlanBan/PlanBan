# Орбитальный рубеж — 1.0

Двухмерная игра защиты космической станции на **Godot 4.7.2**. Высаживайте роботов из семян, собирайте энергию и отражайте киборгов на пяти дорожках. На заднем плане — звёзды и планета текущего сектора.

## Что входит

- Главное меню, карта кампании, ангар, подготовка к миссии, пауза, победа и поражение.
- **50 последовательно открывающихся уровней** в пяти секторах: Лазурная орбита, Изумрудный пояс, Пески Титана, Ледяной спутник, Сердце туманности.
- Каждое первое прохождение уровня выдаёт **своё новое семя**. Всего **53 семени**: три начальных и 50 наградных. Повторная победа улучшает звёзды, но не дублирует награду.
- Девять классов роботов и шесть классов киборгов. Семена относятся к классам, но отличаются именем, уровнем и параметрами; это не 53 совершенно разных базовых механики.
- Набор до шести семян, который можно менять в ангаре перед миссией.
- 10 боссов, быстрые рейды, броневые конвои, редкая внешняя энергия, ЭМИ и препятствия.
- Автосохранение открытых уровней, семян, набора, лучших звёзд и настройки звука; резервная копия сохранения.
- Собственные SVG-рисунки, эффекты и синтезированная музыка. Blender и внешние ассеты не требуются.

Кампания использует общий набор механик с заданными для каждого уровня составами волн, сложностью, условиями и наградами. Это один режим защиты станции, без сетевой игры и сюжетных роликов.

## Запуск готовой версии на Windows

1. Скачайте **OrbitGuardians-Windows.zip** из репозитория.
2. Распакуйте архив целиком.
3. Запустите **OrbitGuardians.exe**. Устанавливать Godot для этой сборки не нужно.
4. Выберите «Начать кампанию», прочитайте условия миссии и нажмите «В бой».

Сборка предназначена для 64-битной Windows. Запуск Windows-исполняемого файла в облачной Linux-среде не проверялся; здесь проверены исходный проект, управление, отрисовка и экспортированная Linux-версия.

## Запуск исходного проекта

Распакуйте **OrbitGuardians-Source.zip**, импортируйте `OrbitGuardians/project.godot` в стандартную версию **Godot 4.7.2** и нажмите **F5**. Версия .NET не нужна. Для повторного экспорта установите официальные шаблоны Godot 4.7.2 и используйте готовые пресеты Windows или Linux.

## Роботы

| Класс | Способность |
| --- | --- |
| Импульс | Обычный выстрел по своей дорожке |
| Реактор | Регулярно производит энергию |
| Бастион | Принимает удары и останавливает врага |
| Криобот | Замедляет противника |
| Спарка | Выпускает два заряда за залп |
| Рельсотрон | Пробивает несколько целей одним зарядом |
| Комета | Наносит урон взрывом, включая соседнюю дорожку |
| Механик | Ремонтирует соседних роботов по горизонтали и вертикали |
| Сверхновая | Через 5 секунд взрывается и исчезает |

Реакторы ставьте в тылу, стрелков — за щитами. Собирайте голубые энергокапсулы кликом: через 15 секунд они исчезают. На каждой активной дорожке есть один аварийный дрон. Он уничтожит всех киборгов при первом прорыве; второй прорыв означает поражение.

После первых трёх побед семена автоматически попадут в свободные места набора. Затем выбирайте нужные в ангаре. Нажатие на карточку набора снимает её; карточка коллекции показывает характеристики и кнопку добавления. Нельзя начать миссию без боевого робота.

## Управление

- **1–6:** выбрать семя из набора.
- **Левая кнопка мыши:** посадить робота на свободную клетку или собрать энергокапсулу.
- **7 / правая кнопка:** разбор робота с возвратом 25% энергии, округление вниз.
- **Пробел / Esc:** пауза; в паузе — продолжить.
- **Enter:** продолжить из меню, начать миссию, перейти к следующей после победы.
- **M:** музыка и эффекты.

Три звезды выдаются за победу без потерь аварийных дронов; две — при потере не более двух; одна — за остальные победы. Награда выдаётся при любом количестве звёзд.

## Сохранения

Игра хранит `orbit_progress.json` и резервный `orbit_progress.json.bak` в своей папке данных Godot. Обычно Windows: `%APPDATA%/Godot/app_userdata/Орбитальный рубеж/`. Архивы не содержат чужих сохранений, и новая установка начинается с первого уровня. Сохранение происходит после победы, изменения набора и настройки звука; незавершённая миссия не сохраняется.

## Проверки и разработка

```sh
godot --headless --path . --editor --import
godot --headless --path . --script res://tests/checks.gd
godot --headless --path . --script res://tests/campaign.gd
```

Первый тест проверяет 40 сценариев механик и сохранений. Второй проходит все 50 миссий детерминированным игроком с обычной экономикой, собирая энергию и покупая доступных роботов; бесплатная энергия и мгновенное уничтожение врагов не используются. Тесты работают с отдельными временными файлами сохранения.

- `scripts/content.gd` — уровни, награды и характеристики классов.
- `scripts/orbit.gd` — бой, ввод, награды и переключение экранов.
- `scripts/view.gd` — космос, интерфейс, поле и визуальные эффекты.
- `scripts/progress.gd` — сохранение и восстановление прогресса.
- `assets/*.svg`, `audio/*.wav` — готовые ресурсы.
- `tools/generate_assets.py` — воспроизводит собственную графику и звук стандартным Python.

Существующие проекты репозитория оставлены без изменений. «Роса и нежить» — предыдущая версия; эта игра развивается в папке `OrbitGuardians/`.
