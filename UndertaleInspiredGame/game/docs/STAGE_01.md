# Stage 1 — Project skeleton

Target: Godot 4.7.2 stable.

Created:
- `project.godot` with main scene, autoload and base inputs.
- `scenes/menu/MainMenu.tscn` with editor-editable UI and AnimationPlayer background motion.
- `scripts/main_menu.gd` for scene switching only.
- `scripts/game_state.gd` autoload for HP, chapter, flags, inventory and mercy/fight route counters.
- `scenes/world/PrototypeRoom.tscn` as a safe destination for the Play button until Stage 2 replaces it with exploration gameplay.

No level visuals are generated by code. Scene visuals are normal Godot nodes and can be edited in the inspector/2D editor.
