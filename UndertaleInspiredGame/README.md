# UndertaleInspiredGame

Отдельный Godot 4.7.2 проект: оригинальная сюжетная RPG, вдохновлённая общим ритмом Undertale, но без копирования персонажей, спрайтов, музыки, карт, диалогов или сюжета Undertale.

## Главное правило
Этот проект ведётся ТОЛЬКО в папке `UndertaleInspiredGame/`.
Старый `AbandonedJungleGame/` остаётся архивом/источником предыдущих наработок и не является активной папкой V4.

Перед любой новой работой обязательно читать:
1. `CURRENT_STATUS.md`
2. `ROADMAP.md`
3. `WORKFLOW.md`
4. `LAST_ACTION.md`

После каждого завершённого этапа обязательно обновлять `CURRENT_STATUS.md` и `LAST_ACTION.md`, затем сохранять чекпоинт.
