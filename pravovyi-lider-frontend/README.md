# Pravovyi Lider — frontend demo

Статична фронтенд-оболонка, зроблена за структурою та візуальним напрямом сайту pravovyilider.com.ua.

## Що є в проєкті

- адаптивний sticky-header і мобільне меню;
- hero-блок з формою;
- блоки статистики, «Про нас», послуги, команда, відгуки, офіси та FAQ;
- фронтенд-валідація форм і demo-toast без відправлення даних;
- простий слайдер відгуків;
- анімації появи елементів;
- жодного бекенду, API чи бази даних.

## Запуск

Можна просто відкрити index.html у браузері або запустити локальний статичний сервер:

    python -m http.server 8080

Після цього відкрити http://localhost:8080.

## Примітка

Один демонстраційний фон у секції «Про нас» завантажується з публічного ресурсу референсного сайту. Інші візуальні елементи створені з CSS/SVG і не потребують локальних зображень.
