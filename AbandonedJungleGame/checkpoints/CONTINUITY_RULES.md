# Continuity rules

For every future work turn on this game:

- Read `../WORKFLOW.md`, `../CURRENT_STATUS.md`, and `../PROJECT_PLAN.md` first.
- Check the latest GitHub commit/checkpoint before editing.
- Continue the current unfinished milestone unless the user explicitly requests a different task.
- Do not silently create a second parallel project copy.
- After each completed logical step, commit the changed source files to this same repository location.
- Update `CURRENT_STATUS.md` after each step with exact changed files, what was tested, and the next action.
- After major milestones, also create a ZIP checkpoint for download.

This file exists specifically to prevent work loss after interruptions or model/context limits.
