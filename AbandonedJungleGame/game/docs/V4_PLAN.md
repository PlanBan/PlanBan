# V4 — original Undertale-inspired rebuild

Target: Godot 4.7.2 stable.

This version keeps the user's project history but changes the active game into an original top-down narrative RPG with turn-based command choices and dodge-box enemy turns. It must NOT copy Undertale characters, dialogue, music, sprites, maps, or story.

## Core structure
- Top-down exploration instead of the old platformer as the primary gameplay.
- German dialogue for all bosses.
- Battle commands: KÄMPFEN / HANDELN / ITEM / VERSCHONEN.
- Red-heart dodge arena during enemy turns.
- Fight timing meter during player attacks.
- ACT/MERCY route as an alternative to defeating bosses.
- Multiple sequential areas and bosses.

## Planned areas and bosses
1. Moosruinen — Moosritter
2. Glasgarten — Glasfalter
3. Versunkenes Archiv — Wurzelarchivar
4. Herzkammer — Uralter Wächter

## Persistence rule
Save a checkpoint after: V4 framework, each completed chapter/boss pair, validation, and final ZIP. V3 remains recoverable and must not be overwritten as the only recovery copy.
