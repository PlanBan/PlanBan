# Asset sources and licenses

This file documents the third-party art currently used by the active V2 scenes.

## Kenney — New Platformer Pack 1.1

Used/derived asset:
- Bee enemy artwork (`assets/enemies/bee_a.svg`, `assets/enemies/bee_b.svg`). The source pack contains `bee_a.png` and `bee_b.png`; the project keeps editor-friendly local SVG variants for the game scene.

Creator/distributor: Kenney — https://kenney.nl/
Source mirror used while assembling the prototype: `eturner58/game-assets`, path `kenney/2D assets/New Platformer Pack/`.
License: Creative Commons Zero (CC0 1.0).
License reference: https://creativecommons.org/publicdomain/zero/1.0/

The pack's included license states that the content may be used for personal, educational and commercial purposes, and that crediting Kenney is appreciated but not required.

## Project-created V2 assets

The following assets were created specifically inside this prototype and are not copied from an external art/audio pack:
- `assets/characters/explorer_v2/*.svg`
- `assets/environment/v2/*.svg`
- `assets/audio/sfx/*.wav`
- `assets/audio/music/jungle_ambience.ogg`
- scene-authored ruin/terrain geometry in `scenes/**/*.tscn`

These are kept as ordinary local project files so they can be replaced or edited later without changing the gameplay scripts.
