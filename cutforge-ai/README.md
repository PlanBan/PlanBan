# CutForge AI v0.3 — локальный редактор Node.js + Python

**Для Windows / PowerShell.** Сайт работает исключительно на компьютере по адресу `http://127.0.0.1:8000`: никакой Cloudflare, аренды сервера или отправки роликов в облако. Node.js отвечает за загрузки, проекты, таймлайн и рендер FFmpeg; Python (без внешних pip-пакетов) через FFmpeg ищет паузы и возвращает рекомендации в Node.js.

## Требования

- Node.js **20+** (рекомендуется версия LTS); `node --version`.
- Python **3.10+**; `py -3 --version` либо `python --version`. При установке Windows отметь **Add Python to PATH**.
- FFmpeg с `ffprobe` и кодеками H.264/AAC должен быть доступен из PATH: `ffmpeg -version` и `ffprobe -version`.
- Для Windows можно установить FFmpeg из Terminal: `winget install --id Gyan.FFmpeg -e`; потом **закрыть и открыть PowerShell снова**.
- Свободное место под оригиналы и экспорт; для видео 90 минут место зависит от битрейта и качества, желательно запас в несколько размеров исходного файла.

## Как запускать

1. Распакуй ZIP полностью (не запускай файлы прямо в архиве).
2. Открой PowerShell именно в папке `cutforge-ai`, где лежит `package.json`.
3. Выполни **по порядку**:

```powershell
npm.cmd install
npm.cmd run build
npm.cmd run dev
```

4. Открой `http://127.0.0.1:8000` в Chrome/Edge. Не закрывай окно PowerShell, пока работаешь с редактором.
5. Чтобы остановить сервер: `Ctrl+C`.

Проверка всех интеграционных функций (необязательно):

```powershell
npm.cmd test
```

`npm.cmd install` здесь не скачивает сторонние npm-пакеты; для проекта используются встроенные библиотеки Node.js. `npm.cmd run build` проверяет синтаксис Node.js, Python-обработчик и собирает в `dist/` три статических файла. `npm.cmd run dev` запускает HTTP-сервер, а Python вызывается при анализе пауз. Переменная `CUTFORGE_SERVE_BUILD=1` позволяет раздавать созданные в `dist/` файлы вместо исходников.

## Возможности

- Загружать видео MP4, MOV, MKV, WebM, M4V до 25 GiB по частям 8 MiB.
- Автоматически искать паузы (Python + FFmpeg), выбирать какие удалять, возвращать фрагменты исходника.
- Ручной редактор: разделение/удаление/подрезка клипов, отмена, 5 цветовых пресетов.
- Загружать свои звуковые эффекты и папки SFX, расставлять их по таймлайну.
- Сохранять проекты, редактировать без изменений оригинала; экспортировать MP4 H.264/AAC, получать ссылку скачивания.
- Python анализ выполняется **в фоновом задании**, а браузер опрашивает статус — продолжительное вычисление не блокирует один HTTP-ответ.

## 90 минут и больше

Сервис проверен на синтетическом видео длительностью **5400 секунд (90 минут)**: Python нашёл интервал тишины. В редакторе доступно **до 500 клипов** и **до 40 звуковых эффектов**. Это не означает, что полноценный 90-минутный рендер с сотнями переходов проверен на твоём ПК: скорость и успешность зависят от железа, свободного диска, исходных кодеков и числа фрагментов. Очень длинные видео лучше сначала испытать на копии.

## Как устроен проект

- `package.json` — команды npm на **верхнем уровне**.
- `scripts/dev.mjs` — запуск Node, проверка FFmpeg и Python.
- `scripts/build.mjs` — сборка и проверка целостности.
- `node-server/server.mjs` — веб-сервер + REST API + FFmpeg-экспорт.
- `python-workers/silence.py` — Python-анализатор пауз на стандартной библиотеке.
- `frontend/` — интерфейс.
- `data/` — личные проекты, исходники, эффекты и результаты; **не загружай эту папку в GitHub**.
- `PROGRESS.md` — прогресс и восстановление после прерывания работы.

## При ошибке

- `npm.cmd : команда не найдена` — установи Node.js 20+ и перезапусти PowerShell.
- `Python 3.10+ не найден` — установи Python и проверь `py -3 --version`.
- `FFmpeg/FFprobe не найдены` — установи FFmpeg, проверь `ffmpeg -version` и перезапусти PowerShell.
- `занят порт 8000` — уже запущен другой экземпляр; закрой старый PowerShell с редактором.
- `Cannot find package.json` — перейди внутрь распакованной папки `cutforge-ai`.
- Страница не открылась автоматически — это нормально: открой URL вручную.
- Видео MOV/MKV может импортироваться, но для предпросмотра в браузере иногда нужна конвертация в MP4 H.264.

После ошибок сохрани точный текст из PowerShell, не отправляй пароли и ключи.

## Ограничения безопасности

Приложение привязано к `127.0.0.1`, предназначено для одного пользователя на ПК, **не публикуй порт 8000 или локальную папку через Cloudflare Tunnel без добавления авторизации и тщательной проверки безопасности**. Нет полноценного семантического ИИ, автоматической вставки мемов, многослойной анимации, трекинга. Паузы определяются по аудио, игровые сцены без речи требуют ручной проверки. Незавершённый рендер при перезапуске сервера нужно запустить заново; сохранённые правки останутся.
