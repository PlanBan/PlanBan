# CutForge AI · Local-first video editor

Рабочий MVP личного браузерного видеоредактора. Исходное видео не изменяется: проект хранит таймлайн и настройки в JSON. Программа слушает только `127.0.0.1`, обработка и экспорт происходят на вашем ПК.

## Что работает

- Импорт локального видео (MP4, MOV, MKV, WebM, M4V; до 25 GiB).
- Автоматический поиск длинных периодов тишины через FFmpeg; каждый предлагаемый разрез можно отключить.
- Ручной таймлайн: разделить клип по текущему кадру, удалить клип, вернуть исходный монтаж, выбрать сегмент и настроить его начало/конец.
- Цветовые пресеты для всего видео.
- Загружать свои аудиоэффекты, размещать их по времени и добавлять в готовый звук.
- Сохранение проекта и фоновый экспорт H.264/AAC MP4 с прогрессом.

## Системные требования

Python 3.10+, FFmpeg с ffprobe в PATH (включая `libx264` и `aac`). На компьютере нужно свободное место для исходного и готового видео.

## Первый запуск

```bash
cd cutforge-ai
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r backend/requirements.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`.

Фронтенд написан без сборки (HTML/CSS/JavaScript), работает офлайн. При изменении файлов `frontend/` просто обновите страницу.

## Ограничения MVP

- Монтаж без потерь оригинала, но экспорт перекодирует видео; рендеринг длинного 4K может быть медленным.
- Нельзя одновременно иметь больше 120 клипов и 40 звуковых эффектов в одном рендере.
- Автопоиск использует **тишину в аудио**, а не смысл видео. Игровые сцены без речи нужно проверять вручную.
- Не поддерживает настоящий drag-to-reorder, субтитры и распознавание речи; это следующие этапы.
- Фоновые задания хранятся в памяти процесса: после перезапуска незавершённый рендер считается прерванным (редактирование уже сохранено).
- Работает локально; приложение не предназначено для размещения в открытом интернете без дополнительной авторизации и защиты.

## Упрощённый запуск

- Windows: после установки Python и FFmpeg запустите `start-windows.bat`.
- macOS/Linux: `bash start-linux-mac.sh`.

Оба скрипта готовят изолированное Python-окружение и запускают локальный сервер. Откройте браузер по адресу `http://127.0.0.1:8000`.

## Windows: исправление проблем при запуске (v0.1.1)

1. В Проводнике Windows нажмите правой кнопкой на ZIP → «Извлечь всё». Запуск из окна архива не поддерживается.
2. Откройте распакованную папку `cutforge-ai` и запустите `START_CUTFORGE_WINDOWS.cmd`.
3. Если запуску мешает отсутствие Python/FFmpeg, окно покажет конкретную ошибку и команды установки.
4. Дождитесь появления `http://127.0.0.1:8000` и откройте его в браузере. Не закрывайте окно запуска во время работы.
5. Если есть ошибка, пришлите скриншот окна запуска или последние строки; личные данные и ключи отправлять не нужно.

Подробнее: `WINDOWS-HELP.txt`. Диагностика настроена без удаления личных видео и проектов.
